# DF PDF Merger – Einrichtungsanleitung

## GitHub Repository erstellen
1. github.com → „+" → „New repository"
2. Name: `df-pdfmerger`
3. Public + README → „Create repository"

## Dateien hochladen
Lade folgende 5 Dateien hoch:
- `index.html`
- `manifest.json`
- `sw.js`
- `icon-192.png`
- `icon-512.png`

## GitHub Pages aktivieren
Einstellungen → Seiten → Branch: main / (root) → Speichern

## Deine App-Adresse
`https://DEINNAME.github.io/df-pdfmerger`

## So funktioniert die App
1. PDFs antippen oder hineinziehen
2. Seiten werden als Vorschaubilder angezeigt
3. ↑ ↓ zum Umsortieren
4. ✓ / ○ zum Ein- und Ausblenden
5. ✕ zum Löschen einer Seite
6. „Speichern" → fertige PDF herunterladen
